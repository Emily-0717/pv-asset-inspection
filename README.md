## 背景

业务机会并非直接“做一个 AI 识别积灰/遮挡的模型”，而是在晴天发电量偏低事件中，建立可核对的异常分流与排查辅助能力，降低手工排查的时效与返工。最终原因需由访谈和运行记录核实，当前报告中的基线与角色均为待确认草案。
